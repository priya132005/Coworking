# 🏢 Coworking – A Modern Coworking Space Booking Platform

Coworking is a modern web application that allows users to easily discover, explore, and book shared office spaces and meeting rooms. Whether you're a freelancer, startup, or enterprise, Coworking provides a seamless and efficient workspace rental experience.

## 🚀 Features

- 🔍 **Advanced Search** – Filter coworking spaces based on location, price, availability, and amenities.
- 📆 **Real-Time Booking** – Reserve office spaces, meeting rooms, or hot desks in real-time.
- 🖼️ **Beautiful UI** – Responsive and modern design using Tailwind CSS and React.
- 💬 **Authentication** – User sign-up, login, and session handling.
- 📊 **Admin Dashboard** – Manage listings, bookings, users, and analytics.
- 📱 **Mobile-Friendly** – Fully responsive design for all device sizes.

## 🛠️ Tech Stack

### Frontend
- **React.js** with Vite
- **Tailwind CSS** for styling
- **Framer Motion**, **Swiper.js** for animations and sliders

### Backend
- **Node.js** + **Express.js**
- **MongoDB** + **Mongoose**
- **JWT** for Authentication
- **Multer** for file uploads

### Dev Tools
- **VS Code**, **Postman**, **GitHub**
- **Figma** for design prototypes
